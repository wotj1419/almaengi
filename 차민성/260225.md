## React 함수형 컴포넌트 이해

React는 UI를 작은 단위의 컴포넌트로 나누어 개발한다.  
각 컴포넌트는 독립적인 기능을 가지며, 재사용이 가능하다.

### 기본 예시

```jsx
function Button({ label }) {
  return <button>{label}</button>;
}

export default Button;
```

### 함수형 컴포넌트의 특징

- 하나의 컴포넌트는 하나의 역할만 수행하도록 설계
- UI와 로직을 함께 관리
- 재사용성을 고려한 구조 설계가 중요
- 상태 관리는 `useState`, 부수 효과는 `useEffect` 활용

---

## Props vs State 정리

### Props

- 부모 → 자식으로 전달되는 값
- 읽기 전용 (자식 컴포넌트에서 직접 수정 불가)
- 컴포넌트 재사용성에 핵심적인 역할

```jsx
<Card title="계좌 잔액" amount="1,200,000원" />
```

Props를 활용하면 하나의 Card 컴포넌트로  
잔액, 거래 수, 포인트 등 다양한 정보를 표현할 수 있다.

---

### State

- 컴포넌트 내부에서 관리되는 값
- 사용자 입력, 버튼 클릭 등으로 변경 가능
- 화면을 동적으로 변화시키는 역할

```jsx
import { useState } from "react";

function Balance() {
  const [balance, setBalance] = useState(0);

  return (
    <div>
      <p>현재 잔액: {balance}원</p>
      <button onClick={() => setBalance(balance + 1000)}>
        +1000원
      </button>
    </div>
  );
}
```

Props는 “외부에서 주입되는 데이터”,  
State는 “내부에서 관리되는 데이터”라고 이해했다.

## 핀테크 서비스에서 컴포넌트 분리 전략

금융 서비스는 **정확성 + 신뢰성 + 유지보수성**이 중요하다.  
따라서 UI도 기능 단위로 명확히 분리해야 한다.

### 예시 폴더 구조

```bash
components/
 ┣ account/
 ┃ ┣ AccountSummary.jsx
 ┃ ┣ AccountHistory.jsx
 ┃ ┗ TransactionItem.jsx
 ┣ common/
 ┃ ┣ Button.jsx
 ┃ ┣ Input.jsx
 ┃ ┗ Modal.jsx
```

### 분리 기준

- 기능 단위로 분리 (계좌 요약 / 거래 내역 / 송금 폼)
- 재사용 가능 UI는 common 폴더에 분리
- API 요청 로직과 UI 로직은 분리
- 숫자 포맷팅, 날짜 변환 등은 util 함수로 분리

---

## 재사용 가능한 컴포넌트 설계 원칙

### 단일 책임 원칙 (Single Responsibility Principle)

한 컴포넌트는 한 가지 역할만 수행해야 유지보수가 쉽다.

잘못된 구조  
로그인 처리 + API 호출 + 화면 출력 모두 한 파일에 작성

개선 구조
- `LoginForm` → UI
- `useLogin` → 로직
- `authService` → API 호출

---

### 확장 가능한 설계

핀테크 서비스는 기능이 계속 추가될 가능성이 높다.  
따라서 props 기반으로 확장 가능한 구조를 설계해야 한다.

```jsx
<Button
  variant="primary"
  size="large"
  onClick={handleSubmit}
/>
```

`variant`, `size` 등을 분리해두면  
다양한 상황에서 재사용이 가능하다.

## 금융 UI 설계 시 고려사항

### 1. 정보 우선순위

금융 서비스에서는 사용자가 가장 중요하게 보는 정보가 명확하다.

- 잔액
- 최근 거래 내역
- 알림
- 송금 버튼

따라서 상단에 핵심 정보를 배치해야 한다.

---

### 2. 실수 방지 UX 설계

금융 서비스는 “실수 최소화”가 중요하다.

- 송금 시 금액 재확인 모달
- 버튼 비활성화 처리
- 로딩 상태 표시
- 중복 클릭 방지

```jsx
<button disabled={isLoading}>
  {isLoading ? "처리 중..." : "송금하기"}
</button>
```

---

### 3. 신뢰감을 주는 UI

- 일정한 간격 유지
- 명확한 숫자 포맷팅 (예: 1,000,000원)
- 에러 메시지를 구체적으로 표시
- 색상 사용 시 의미를 명확히 (빨강 = 위험)
