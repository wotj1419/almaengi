## 동기 vs 비동기 이해

### ✔ 동기(Synchronous)

코드가 위에서 아래로 순차적으로 실행된다.  
이전 작업이 끝나야 다음 작업이 실행된다.

문제점:
- 서버 요청처럼 시간이 오래 걸리는 작업이 있으면 화면이 멈출 수 있다.

---

### ✔ 비동기(Asynchronous)

오래 걸리는 작업은 따로 처리하고,  
다음 코드가 먼저 실행된다.

대표적인 비동기 작업:
- API 요청
- 파일 업로드
- 결제 요청
- 로그인 인증 요청

핀테크 서비스에서는 대부분의 작업이 서버 통신을 포함하기 때문에  
비동기 처리가 필수적이다.

## Promise와 async/await

### ✔ Promise 기본 구조

```javascript
fetch("/api/account")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));
```

가독성이 떨어질 수 있다.

---

### ✔ async/await 방식

```javascript
async function getAccount() {
  try {
    const response = await fetch("/api/account");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}
```

✔ 코드가 동기처럼 보여 가독성이 좋다  
✔ 에러 처리가 명확하다

## Axios를 활용한 API 요청

핀테크 프로젝트에서는 fetch보다 Axios를 많이 사용한다.  
이유:
- 자동 JSON 변환
- 인터셉터 지원
- 에러 처리 구조 명확
- 토큰 자동 첨부 가능

### ✔ Axios 설치

```bash
npm install axios
```

---

### ✔ 기본 GET 요청

```javascript
import axios from "axios";

async function getBalance() {
  try {
    const response = await axios.get("/api/account/balance");
    console.log(response.data);
  } catch (error) {
    console.error(error);
  }
}
```

---

### ✔ POST 요청 (송금 예시)

```javascript
async function transferMoney(amount) {
  try {
    const response = await axios.post("/api/transfer", {
      amount: amount,
    });
    console.log(response.data);
  } catch (error) {
    console.error(error);
  }
}
```

## JWT 토큰 포함 요청 구조

핀테크 서비스는 인증이 필수다.  
따라서 모든 요청에 토큰이 포함된다.

```javascript
axios.get("/api/account", {
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
});
```

---

### ✔ Axios 인스턴스 분리

```javascript
import axios from "axios";

const api = axios.create({
  baseURL: "/api",
});

api.interceptors.request.use(config => {
  const token = localStorage.getItem("accessToken");
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

export default api;
```

✔ 모든 요청에 자동으로 토큰 포함  
✔ 코드 중복 제거  
✔ 유지보수성 향상

## 로딩 및 에러 상태 관리

핀테크 서비스에서는 사용자가 “멈춘 화면”을 보면 안 된다.  
반드시 로딩 상태를 표시해야 한다.

```javascript
const [isLoading, setIsLoading] = useState(false);
const [error, setError] = useState(null);

async function fetchData() {
  setIsLoading(true);
  setError(null);

  try {
    const response = await api.get("/account");
    console.log(response.data);
  } catch (err) {
    setError("데이터를 불러오는 데 실패했습니다.");
  } finally {
    setIsLoading(false);
  }
}
```
