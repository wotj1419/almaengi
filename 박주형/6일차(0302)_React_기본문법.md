# React 기초 문법 (feat. Vue 복습 비교)

>
> **작성일**: 2026-03-06
>
> **목표**: React의 핵심 문법을 Vue와 비교하며 빠르게 익히기
>
> **키워드**: `React` `JSX` `useState` `컴포넌트` `Props` `이벤트 처리` `Vue 비교` `Vite`

---

## 1. React란?

React는 Facebook(현 Meta)이 만든 **UI 라이브러리**다. Vue와 마찬가지로 컴포넌트 기반으로 UI를 구성하지만, 접근 방식에 차이가 있다.

| 구분 | Vue | React |
|------|-----|-------|
| 유형 | 프레임워크 (배터리 포함) | 라이브러리 (직접 조합) |
| 템플릿 | HTML 기반 `<template>` | JavaScript 기반 JSX |
| 데이터 바인딩 | 양방향 (`v-model`) | 단방향 (state → UI) |
| 학습 곡선 | 완만함 | JSX 적응 필요 |
| 상태 변경 | `ref.value = x` 로 직접 변경 | `setState(x)` 함수 호출 |

**핵심 차이:** Vue는 "HTML을 확장"하는 느낌이라면, React는 "JavaScript 안에서 UI를 작성"하는 느낌이다.

## 2. 개발 환경 세팅

### Vue (복습)

```bash
npm create vue@latest my-vue-app
cd my-vue-app
npm install
npm run dev
```

### React (Vite 사용)

```bash
npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install
npm run dev
```

두 가지 모두 Vite를 번들러로 사용할 수 있다. React 프로젝트를 만들면 아래와 같은 구조가 생긴다:

```
my-react-app/
├── public/
├── src/
│   ├── App.jsx          ← 메인 컴포넌트
│   ├── main.jsx         ← 진입점 (Vue의 main.js와 동일)
│   └── assets/
├── index.html
├── package.json
└── vite.config.js
```

Vue의 `App.vue` → React의 `App.jsx`, Vue의 `main.js` → React의 `main.jsx`로 대응된다.

## 3. JSX 문법 — Vue의 `<template>`과 비교

JSX는 JavaScript 안에서 HTML처럼 생긴 코드를 작성하는 문법이다. Vue의 `<template>` 블록이 별도로 존재하는 것과 달리, React는 함수의 return 안에 JSX를 직접 작성한다.

### 기본 구조 비교

**Vue:**
```vue
<template>
  <div>
    <h1>{{ title }}</h1>
    <p>{{ description }}</p>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const title = ref('안녕하세요')
const description = ref('Vue 컴포넌트입니다')
</script>
```

**React:**
```jsx
import { useState } from 'react'

function App() {
  const [title] = useState('안녕하세요')
  const [description] = useState('React 컴포넌트입니다')

  return (
    <div>
      <h1>{title}</h1>
      <p>{description}</p>
    </div>
  )
}

export default App
```

**차이점 정리:**
- Vue: `{{ }}` 이중 중괄호로 데이터 바인딩 → React: `{ }` 단일 중괄호
- Vue: `<template>`, `<script>`, `<style>` 영역 분리 → React: 하나의 함수 안에 모두 작성
- Vue: `.vue` 파일 → React: `.jsx` 파일

### JSX에서 주의할 점

```jsx
// ❌ class가 아니라 className
<div className="container">

// ❌ for가 아니라 htmlFor
<label htmlFor="email">

// ❌ style은 객체로 전달
<div style={{ backgroundColor: 'blue', fontSize: '16px' }}>

// ❌ 반드시 하나의 루트 요소로 감싸야 함 (Fragment 사용 가능)
return (
  <>
    <h1>제목</h1>
    <p>내용</p>
  </>
)
```

## 4. 조건부 렌더링

### Vue (복습): `v-if` / `v-else` / `v-show`

```vue
<template>
  <div v-if="isLoggedIn">환영합니다!</div>
  <div v-else>로그인해주세요</div>

  <!-- v-show는 CSS display로 토글 -->
  <div v-show="isVisible">보였다 안보였다</div>
</template>

<script setup>
import { ref } from 'vue'
const isLoggedIn = ref(false)
const isVisible = ref(true)
</script>
```

### React: 삼항 연산자 / && 연산자

```jsx
import { useState } from 'react'

function App() {
  const [isLoggedIn, setIsLoggedIn] = useState(false)
  const [isVisible, setIsVisible] = useState(true)

  return (
    <div>
      {/* 삼항 연산자 = v-if / v-else */}
      {isLoggedIn ? <div>환영합니다!</div> : <div>로그인해주세요</div>}

      {/* && 연산자 = v-if (else 없을 때) */}
      {isVisible && <div>보였다 안보였다</div>}
    </div>
  )
}
```

**비교 요약:**
| Vue | React | 설명 |
|-----|-------|------|
| `v-if` / `v-else` | 삼항 연산자 `? :` | 조건에 따라 다른 요소 렌더링 |
| `v-if` (단독) | `&&` 연산자 | 조건이 true일 때만 렌더링 |
| `v-show` | `style={{ display: ... }}` | DOM은 유지, CSS로 숨김 |

## 5. 반복 렌더링 (리스트)

### Vue (복습): `v-for`

```vue
<template>
  <ul>
    <li v-for="item in items" :key="item.id">
      {{ item.name }}
    </li>
  </ul>
</template>

<script setup>
import { ref } from 'vue'
const items = ref([
  { id: 1, name: '사과' },
  { id: 2, name: '바나나' },
  { id: 3, name: '딸기' },
])
</script>
```

### React: `map()`

```jsx
import { useState } from 'react'

function App() {
  const [items] = useState([
    { id: 1, name: '사과' },
    { id: 2, name: '바나나' },
    { id: 3, name: '딸기' },
  ])

  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  )
}
```

**핵심:** Vue의 `v-for`는 디렉티브로 제공되지만, React는 JavaScript의 `Array.map()`을 그대로 사용한다. `key` 속성은 둘 다 필수!

## 6. 컴포넌트 만들기

### Vue (복습): SFC (Single File Component)

```vue
<!-- components/Greeting.vue -->
<template>
  <div class="greeting">
    <h2>안녕하세요, {{ name }}님!</h2>
    <p>{{ message }}</p>
  </div>
</template>

<script setup>
defineProps({
  name: { type: String, required: true },
  message: { type: String, default: '반갑습니다' }
})
</script>
```

사용:
```vue
<template>
  <Greeting name="철수" message="좋은 하루 되세요" />
</template>
```

### React: 함수형 컴포넌트

```jsx
// components/Greeting.jsx
function Greeting({ name, message = '반갑습니다' }) {
  return (
    <div className="greeting">
      <h2>안녕하세요, {name}님!</h2>
      <p>{message}</p>
    </div>
  )
}

export default Greeting
```

사용:
```jsx
import Greeting from './components/Greeting'

function App() {
  return <Greeting name="철수" message="좋은 하루 되세요" />
}
```

**비교:**
| 구분 | Vue | React |
|------|-----|-------|
| 파일 구조 | `.vue` (template + script + style) | `.jsx` (함수 하나) |
| Props 정의 | `defineProps()` | 함수 파라미터 구조분해 |
| 기본값 | `default: '값'` | `param = '값'` |
| 가져오기 | 자동 등록 (script setup) | `import`로 직접 가져오기 |

## 7. 이벤트 처리

### Vue (복습)

```vue
<template>
  <button @click="handleClick">클릭</button>
  <input @input="handleInput" />
  <form @submit.prevent="handleSubmit">
    <button type="submit">제출</button>
  </form>
</template>

<script setup>
const handleClick = () => alert('클릭됨!')
const handleInput = (e) => console.log(e.target.value)
const handleSubmit = () => console.log('제출!')
</script>
```

### React

```jsx
function App() {
  const handleClick = () => alert('클릭됨!')
  const handleInput = (e) => console.log(e.target.value)
  const handleSubmit = (e) => {
    e.preventDefault()  // Vue의 .prevent 수식어 대신 직접 호출
    console.log('제출!')
  }

  return (
    <div>
      <button onClick={handleClick}>클릭</button>
      <input onInput={handleInput} />
      <form onSubmit={handleSubmit}>
        <button type="submit">제출</button>
      </form>
    </div>
  )
}
```

**비교:**
| Vue | React | 설명 |
|-----|-------|------|
| `@click` | `onClick` | camelCase로 작성 |
| `@input` | `onInput` / `onChange` | React는 `onChange`를 더 자주 사용 |
| `.prevent` 수식어 | `e.preventDefault()` | React는 수식어 없이 직접 호출 |
| `.stop` 수식어 | `e.stopPropagation()` | 마찬가지로 직접 호출 |

## 8. 실습 예제: 간단한 투두 리스트

같은 기능을 Vue와 React로 나란히 구현해보자.

### Vue 버전

```vue
<template>
  <div>
    <h1>할 일 목록 (Vue)</h1>
    <div>
      <input v-model="newTodo" @keyup.enter="addTodo" placeholder="할 일 입력" />
      <button @click="addTodo">추가</button>
    </div>
    <ul>
      <li v-for="todo in todos" :key="todo.id">
        <span :class="{ done: todo.completed }" @click="toggleTodo(todo.id)">
          {{ todo.text }}
        </span>
        <button @click="removeTodo(todo.id)">삭제</button>
      </li>
    </ul>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const newTodo = ref('')
const todos = ref([])
let nextId = 1

const addTodo = () => {
  if (!newTodo.value.trim()) return
  todos.value.push({ id: nextId++, text: newTodo.value, completed: false })
  newTodo.value = ''
}

const toggleTodo = (id) => {
  const todo = todos.value.find(t => t.id === id)
  if (todo) todo.completed = !todo.completed
}

const removeTodo = (id) => {
  todos.value = todos.value.filter(t => t.id !== id)
}
</script>
```

### React 버전

```jsx
import { useState } from 'react'

function App() {
  const [newTodo, setNewTodo] = useState('')
  const [todos, setTodos] = useState([])
  const [nextId, setNextId] = useState(1)

  const addTodo = () => {
    if (!newTodo.trim()) return
    setTodos([...todos, { id: nextId, text: newTodo, completed: false }])
    setNextId(nextId + 1)
    setNewTodo('')
  }

  const toggleTodo = (id) => {
    setTodos(todos.map(todo =>
      todo.id === id ? { ...todo, completed: !todo.completed } : todo
    ))
  }

  const removeTodo = (id) => {
    setTodos(todos.filter(todo => todo.id !== id))
  }

  return (
    <div>
      <h1>할 일 목록 (React)</h1>
      <div>
        <input
          value={newTodo}
          onChange={(e) => setNewTodo(e.target.value)}
          onKeyUp={(e) => e.key === 'Enter' && addTodo()}
          placeholder="할 일 입력"
        />
        <button onClick={addTodo}>추가</button>
      </div>
      <ul>
        {todos.map((todo) => (
          <li key={todo.id}>
            <span
              className={todo.completed ? 'done' : ''}
              onClick={() => toggleTodo(todo.id)}
            >
              {todo.text}
            </span>
            <button onClick={() => removeTodo(todo.id)}>삭제</button>
          </li>
        ))}
      </ul>
    </div>
  )
}

export default App
```

### 핵심 차이 요약

| 기능 | Vue | React |
|------|-----|-------|
| 양방향 바인딩 | `v-model="newTodo"` | `value={newTodo}` + `onChange` |
| 상태 변경 | `todos.value.push(...)` 직접 변경 | `setTodos([...todos, ...])` 새 배열 생성 |
| 키 이벤트 | `@keyup.enter` | `onKeyUp` + `e.key === 'Enter'` |
| 클래스 바인딩 | `:class="{ done: ... }"` | `className={조건 ? 'done' : ''}` |

**가장 중요한 차이:** Vue는 상태를 **직접 변경(mutation)**할 수 있지만, React는 반드시 **새로운 값을 만들어서 set 함수로 교체(immutable update)**해야 한다. 이것이 React 상태 관리의 핵심 원칙이다.

## 전체 요약 정리

| Vue | React | 핵심 포인트 |
|-----|-------|------------|
| `<template>` HTML 기반 | JSX (JS 안에 HTML) | React는 "모든 것이 JavaScript" |
| `{{ }}` 이중 중괄호 | `{ }` 단일 중괄호 | 데이터 바인딩 문법 |
| `v-if` / `v-for` 디렉티브 | 삼항 연산자 / `map()` | React는 JS 문법을 그대로 활용 |
| `.vue` SFC 파일 | `.jsx` 함수형 컴포넌트 | React가 구조적으로 더 단순 |
| `defineProps()` | 함수 파라미터 구조분해 | Props 전달 방식 |
| `@click` + 수식어 (`.prevent`) | `onClick` + 직접 호출 (`e.preventDefault()`) | 이벤트 핸들링 |
| `v-model` 양방향 바인딩 | `value` + `onChange` 조합 | React는 단방향이 기본 |
| `ref.value = x` 직접 변경 | `setState(x)` 새 값으로 교체 | **가장 중요한 차이: 상태 불변성** |

**한 줄 요약:** Vue가 "편의 기능을 제공"하는 방식이라면, React는 "JavaScript 자체를 활용"하는 방식이다. 상태를 직접 변경하지 않고 항상 새로운 값으로 교체하는 **불변성(immutability)** 원칙이 React의 가장 핵심적인 개념이다.
