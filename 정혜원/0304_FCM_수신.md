## 1. 공통 준비 사항 (Firebase Console)

* **프로젝트 생성:** Firebase Console에서 프로젝트 생성.
* **앱 등록:** Android 앱(Package Name 입력) 및 Web 앱을 각각 등록.
* **설정 파일 다운로드:**
* **Android:** `google-services.json` 다운로드 후 `android/app` 경로에 배치.
* **Web:** `firebaseConfig` 객체(API Key 등) 복사.

---

## 2. React Native (Android 앱) 처리 방법

React Native 환경에서는 공식 라이브러리인 `@react-native-firebase/messaging`을 주로 사용합니다.

### 🔹 환경 설정

* **의존성 설치:** `npm install @react-native-firebase/app @react-native-firebase/messaging`
* **권한 요청 (Android 13+):** Android 13부터는 알림 권한이 동적 권한으로 변경되어 런타임에 요청 필수.

### 🔹 메시지 핸들링 로직

1. **토큰 획득 및 서버 전송:**
```javascript
const token = await messaging().getToken();
// 이 토큰을 백엔드 API로 보내 DB에 저장

```


2. **Foreground (앱 실행 중):**
* `messaging().onMessage` 리스너를 통해 수신.
* 시스템 알림창이 자동으로 뜨지 않으므로, `Alert`이나 `Notifee` 라이브러리로 수동 팝업 노출.


3. **Background/Quit (앱 종료/배후):**
* `index.js` 최상단에 `setBackgroundMessageHandler` 등록.
* 시스템이 알림을 트레이에 자동으로 노출.

## 3. React Web (PWA / Android 브라우저) 처리 방법

안드로이드 크롬 브라우저 등을 통해 웹앱으로 접근할 때의 방식입니다.

### 🔹 서비스 워커(Service Worker) 설정

* **파일 위치:** `public/firebase-messaging-sw.js` (반드시 이 위치와 이름이어야 함).
* **역할:** 웹앱이 꺼져 있어도 브라우저 프로세스에서 알림을 수신하는 '백그라운드 리스너'.
```javascript
// public/firebase-messaging-sw.js
importScripts('https://www.gstatic.com/firebasejs/9.x.x/firebase-app-compat.js');
importScripts('https://www.gstatic.com/firebasejs/9.x.x/firebase-messaging-compat.js');

firebase.initializeApp({ /* config */ });
const messaging = firebase.messaging();

messaging.onBackgroundMessage((payload) => {
  // 백그라운드 알림 커스텀 처리 가능
});

```



### 🔹 프론트엔드 코드 구현

1. **권한 요청:** `Notification.requestPermission()` 호출.
2. **FCM 토큰 생성:** `getToken(messaging, { vapidKey: '...' })` 사용.
3. **포그라운드 리스너:** `onMessage(messaging, (payload) => { ... })`로 실시간 알림 처리.

## 4. Android 기기 특화 주의사항 (중요)

### 🔹 알림 채널 (Notification Channels)

* **Android 8.0(Oreo) 이상:** 반드시 **Channel ID**가 있어야 알림이 보임.
* **방법:** FCM 메시지 페이로드에 `android_channel_id`를 포함하거나, 앱 코드에서 채널을 미리 생성 해야됨.

### 🔹 배터리 최적화 (Doze 모드)

* 안드로이드 기기가 절전 모드일 경우 알림이 지연될 수 있음.
* **해결:** 서버에서 메시지를 보낼 때 **Priority를 'high'** 로 설정해야 즉시 전달됨.

### 🔹 아이콘 설정

* 안드로이드 시스템 트레이에 표시될 **투명 배경의 흰색 아이콘**이 별도로 필요 (컬러 아이콘은 회색 사각형으로 깨질 수 있음).

## 5. 요약 정리 (Cheat Sheet)

| 구분 | React Native (Android) | React Web (PWA) |
| --- | --- | --- |
| **핵심 라이브러리** | `@react-native-firebase/messaging` | `firebase/messaging` |
| **백그라운드 처리** | `setBackgroundMessageHandler` | `firebase-messaging-sw.js` |
| **권한 관리** | `PermissionsAndroid` 또는 라이브러리 활용 | `Notification.requestPermission` |
| **토큰 관리** | 앱 시작 시 `getToken` 갱신 체크 | 서비스 워커 등록 후 `getToken` |
