7년 차 프로젝트 기획자(PM)로서, 지금까지 논의된 **'트래블-세이버(Travel-Saver)'**의 아이디어를 실제 개발 구현이 가능한 수준의 **[상세 기능 정의서]**로 구조화하여 보고합니다.

이 정의서는 2026년 핀테크 표준인 **마이데이터 2.0**과 **자율형 AI 에이전트** 기술을 기반으로 하며, 사용자의 자산 형성부터 여행지에서의 가치 소비까지의 전 과정을 데이터로 연결합니다.

# [기능 정의서] 지능형 여행 자산 관리 플랫폼 '트래블-세이버'

## Level 1. 핵심 기능 (MVP: 자산 형성 인프라 구축)

사용자의 금융 데이터를 안전하게 통합하고, 여행 목적에 맞는 자동화된 저축 환경을 제공합니다.

| 기능 ID | 기능명 | 상세 정의 및 로직 | 관련 기술 및 API |
| --- | --- | --- | --- |
| **F1.1** | **AI 자동 예산 빌더** | 사용자가 선택한 [국가, 도시, 일정, 인원] 정보를 바탕으로 AI가 예상 총 경비를 자동 산출합니다. <br>

<br> - **로직:** (평균 항공가) + (숙박 등급별 평균가) + (현지 물가 기반 식비/교통비 * 일수) | Numbeo API, BudgetYourTrip API, Skyscanner Indicative API |
| **F1.2** | **마이데이터 2.0 통합 자산 연동** | 한 번의 인증으로 사용자의 모든 은행 계좌, 카드 결제 내역, 투자 자산을 자동으로 조회하여 가용 자금을 분석합니다. | 마이데이터 표준 API (전체 금융자산 자동조회) |
| **F1.3** | **BaaS 기반 공유 저축통장** | 친구/연인과 함께 모으는 가상 공유 계좌를 생성합니다. 참여자별 저축 현황을 실시간 모니터링하고 투명한 입출력 관리를 지원합니다. | IBK 기업은행 등 오픈뱅킹 API (잔액/거래내역 조회), BaaS(Banking-as-a-Service) |
| **F1.4** | **지능형 이체 스케줄러** | 설정된 여행 일자까지 목표액 달성을 위해 일별/주별 필요 저축액을 자동 이체합니다. <br>

<br> - **로직:** 사용자의 월 소득 및 지출 패턴을 분석하여 '여유 자금' 내에서 이체 금액을 유동적으로 조절합니다. 

 | 오픈뱅킹 자금이체 API

## Level 2. 차별점 (Intelligent Engine: 실질적 이득 및 동기 부여)

데이터 분석을 통해 사용자의 지출을 최적화하고 행동 경제학적 기법으로 저축 참여를 유도합니다.

| 기능 ID | 기능명 | 상세 정의 및 로직 | 관련 기술 및 API |
| --- | --- | --- | --- |
| **F2.1** | **수익형 재예약(Profit-Quote) 시스템** | 예매한 항공권 가격을 실시간 모니터링하여 재예약 시 이득이 발생하는지 계산합니다. <br>

<br> - **로직:**   <br>

<br> -  일 때만 푸시 알림을 발송합니다. | Duffel Refund Quote API (환불액 산출), Amadeus Mini Rules API (수수료 요약), Kiwi Tequila API |
| **F2.2** | **커피값 절약 게이미피케이션 (Save-to-Go)** | '커피값 아끼기' 버튼 클릭 시 지정된 소액(예: 5,000원)을 즉시 저축합니다. <br>

<br> - **시각화:** "이 절약으로 도쿄 디즈니랜드 간식을 획득했습니다!"와 같은 가치 변환 메시지를 노출합니다. | StriveCloud Gamification 엔진, 행동 분석 알고리즘 |
| **F2.3** | **자율형 업그레이드 큐레이션** | 저축 속도가 빠르거나 목표액을 초과 달성하면, 차액으로 업그레이드 가능한 항목을 제안합니다. <br>

<br> - **예시:** "현재 페이스라면 숙소를 4성급에서 5성급으로 상향할 수 있습니다." | Branded Fares Upsell API (Amadeus), AI 추천 엔진 |
| **F2.4** | **'Tilting' 방지 소비 코칭** | AI가 사용자의 과소비 패턴(지정된 예산 범위를 벗어나는 징후)을 포착하면 "현재 지출 속도라면 여행지에서의 액티비티 1개가 취소될 수 있습니다"라고 경고합니다. | 자율 의사결정 시스템(Autonomous Decision Systems) |

## 4. 비기능적 요구사항 및 보안 정책

1. **데이터 보안 (PQC 적용):** 금융 정보 및 장기 여행 기록 보호를 위해 **격자 기반 암호(Lattice-based Cryptography)** 알고리즘(CRYSTALS-Kyber 등)을 적용하여 양자 컴퓨터의 공격에 대비합니다.
2. **보안 인증 (Zero Trust):** 모든 API 요청 시 신뢰하지 않는 환경을 가정하여 엄격한 신원 확인(DID 등)과 권한 부여 절차를 수행합니다.
3. **시스템 성능 (Optimization):** 항공권 실시간 모니터링 시 발생하는 API 호출 비용과 서버 부하를 최소화하기 위해 **15~30분 단위의 가변 폴링(Polling) 스케줄**과 검색 결과 캐싱 전략을 운영합니다.

## 5. 실행 로드맵 (Execution Roadmap)

1. **기술 검증 (PoC):** 금융보안원 **마이데이터 테스트베드**를 활용하여 표준 API 규격 내에서 가상 결제 데이터와 저축 로직이 안정적으로 맞물리는지 1단계 검증을 완료합니다. 


2. **규제 샌드박스 진입:** '수익형 재예약 자동화'와 '공유 통장 기반 정산' 기능에 대해 **한국핀테크지원센터**의 컨설팅을 거쳐 혁신금융서비스 지정을 신청, 법적 리스크를 해소하고 테스트 비용을 확보합니다. 


3. **AI 거버넌스 수립:** AI가 내리는 금융적 권고(재예약 제안 등)에 대한 투명성을 확보하기 위해 **책임감 있고 설명 가능한 AI(Explainable AI)** 거버넌스 체계를 구축합니다.

이 기능 정의서는 실제 개발 프로젝트의 백로그(Backlog)로 즉각 활용될 수 있을 만큼 상세하게 기획되었습니다. 추가적인 UI/UX 설계나 특정 API의 상세 명세가 필요하시면 바로 말씀해 주세요.
